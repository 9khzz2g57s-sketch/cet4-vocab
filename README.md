# 四级核心词汇 1200 · 学习台

1212 条四级高频核心词汇的单页学习工具：

- **记忆曲线**：1 → 2 → 4 → 7 → 15 → 30 → 60 → 120 天的间隔重复排程
- **学习计划**：7 天冲刺（463 条）/ 30 天标准（1212 条），可设开始日期、按天推进
- **落后自动顺延**：没学完的词自动并入今天，结束日期按实际进度重算
- **打卡计时**：正计时 + 倒计时（番茄钟），每秒自动计入当天
- **四选一自测**、搜索筛选、深浅色主题

全部离线运行，进度存在浏览器本地（localStorage），不上传任何数据。

手机上用 Safari 打开线上地址 → 分享 → 添加到主屏幕，即可当 App 使用并离线访问。
